# Titen AI — APK Android

Repositori ini menyediakan APK, informasi versi, dan notice dependensi Titen AI mobile.

[Unduh rilis terbaru](https://github.com/hudantech/titen-ai-mobile-releases/releases/latest)

Aplikasi Android memeriksa versi saat dibuka. Jika build terbaru tersedia untuk instalasi Anda, popup menawarkan **Update** atau **Nanti**. Pilih Update untuk mengunduh APK, lalu lanjutkan pemasangan melalui Android. Pemeriksaan manual juga tersedia di **Tentang aplikasi → Periksa update aplikasi**.

File APK saat ini mendukung Android ARM64 dan mempertahankan sertifikat internal instalasi pengujian. Gunakan APK dengan identitas signing yang sama untuk memperbarui aplikasi yang sudah terpasang.

Setiap release berisi:

- APK Android.
- SHA-256 APK.
- `android-update.json` untuk pengecekan versi.
- `LICENSES.txt` dan `ANDROID-NOTICES.txt`.

Metadata versi terbaru: [android-update.json](https://github.com/hudantech/titen-ai-mobile-releases/releases/latest/download/android-update.json).

Nomor build Android (`versionCode`) naik pada setiap rilis baru. Metadata dan APK harus berada pada tag release yang sama. Rilis dipublikasikan sebagai **Latest** setelah APK serta file pendamping selesai diunggah dan diverifikasi.
